# Hilal & Sinan ❤️ Özel Aşk Portalı

Bu proje, Hilal ve Sinan için özel olarak hazırlanmış, iPhone kilit açma (Passcode) ekranı deneyimi sunan ve **31.05.2026** tarihine odaklı canlı aşk sayacı barındıran romantik bir web sitesidir.

## ✨ Özellikler

- 📱 **Orijinal iOS Kilit Ekranı (Passcode Keypad):**
  - Gerçekçi iOS 18 cam (frosted glass) tuş takımı ve durum çubuğu (Status Bar).
  - 8 haneli özel şifre doğrulaması: `31052026` (31 Mayıs 2026).
  - Web Audio API ile sıfır harici dosya gecikmesiyle çalışan orijinal iPhone tuş tıklama sesleri ve kilit açılma tınısı.
  - Yanlış şifre girildiğinde kırmızı uyarı ve iOS shake (titreme) animasyonu.
  - Fiziksel klavye desteği (0-9 tuşları, Silme ve Enter).
- ⏳ **31.05.2026 Canlı Aşk Sayacı:**
  - 31 Mayıs 2026 tarihine odaklanmış anlık canlı sayaç (Gün, Saat, Dakika, Saniye).
  - Belirtilen tarihe kadar geri sayım, sonrasında ise birlikte geçen zamanı sayan akıllı zaman motoru.
- 💌 **İnteraktif Aşk Mektubu:**
  - Kırmızı balmumu mühürlü özel zarf animasyonu. Tıklanınca açılan romantik mektup.
- 💖 **Neden Hilal? (Aşk Nedenleri Üreteci):**
  - Butona her basıldığında kalpten gelen yeni bir aşk nedeni.
- 🎵 **Romantik Fon Müziği:**
  - Web Audio API destekli kesintisiz romantik melodi ve müzik açma/kapatma kontrolü.
- 🌟 **İnteraktif Partiküller:**
  - Ekrana her dokunulduğunda ve tuşlandığında uçuşan canlı kalp partikülleri.
- 🔒 **Tekrar Kilitleme:**
  - İstenildiği an sayfayı yeniden kilit ekranı moduna alma.

## 🚀 GitHub Pages & Subdomain (hilal.sinankeskin.com.tr) Kurulumu

1. `CNAME` dosyası projenin ana dizininde `hilal.sinankeskin.com.tr` olarak tanımlanmıştır.
2. GitHub repository ayarlarından (**Settings -> Pages**):
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)` seçilip kaydedilir.
   - **Custom domain:** `hilal.sinankeskin.com.tr` otomatik olarak `CNAME` dosyasından okunacaktır.
3. Domain DNS Yönetim Panelinizde:
   - `hilal` adında bir **CNAME** kaydı oluşturup değer olarak `sinan-keskin.github.io` adresini yönlendirmeniz yeterlidir.
